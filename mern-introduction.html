The Big Picture

Why Learn Full-Stack Development?

Every app you use daily — Instagram, Swiggy, Amazon — has a frontend, a backend, and a database working together.

🖥️
Frontend
What users see & interact with — buttons, forms, pages. Built with HTML, CSS, JavaScript, React.
⚙️
Backend
The logic behind the scenes — handles requests, processes data, authenticates users. Built with Node.js & Express.
🗄️
Database
Where data lives — user profiles, orders, messages. We'll use MongoDB, a modern NoSQL database.
Architecture

Client-Server
Architecture

The foundation of how the internet works

  • Client — Your browser (Chrome, Firefox). Sends requests.
  • Server — A remote computer that processes requests & sends back data.
  • HTTP — The protocol (language) they use to talk to each other.
  • API — A set of rules defining how the client & server communicate.
🍕 Real-World Example: Ordering on Swiggy
  1. You open the Swiggy app (Client)
  2. App sends your location to Swiggy's Server
  3. Server fetches nearby restaurants from the Database
  4. Server sends the list back → you see restaurants!

The Stack

What is the
MERN Stack?

  • M
    MongoDB — NoSQL database that stores data as flexible JSON-like documents
  • E
    Express.js — Minimal Node.js framework to build APIs & handle routes
  • R
    React.js — Facebook's library for building fast, interactive UIs with components
  • N
    Node.js — JavaScript runtime that lets you run JS on the server
